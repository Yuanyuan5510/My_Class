# 班级抽签 · Guess One

教室管理系统（核心：随机抽取学生）。**Electron 外壳 + Python 后端 + Vite/React 前端** 三层架构，Windows 桌面应用，支持触摸屏与主题定制。

- 当前版本：**1.0.4**
- 安装包：`release/GuessOne-Setup-1.0.4.exe`（NSIS，可自定义安装目录；安装目录内含 `LICENSE.txt`）
- 主题制作：见 [docs/主题制作指南.md](docs/主题制作指南.md)

## 架构

```
┌─────────────────────────────────────────────────────────┐
│ Electron 外壳（WebView 宿主）                              │
│  · 主窗口（无边框 + 应用内窗口按钮）/ 边缘页签 / 托盘        │
│  · 开机自启 / UAC 提权 / 开发者页窗口                       │
├──────────────────────────┬──────────────────────────────┤
│ Python 后端（独立进程）     │ 前端（Vite + React + TS 构建） │
│  · http.server + REST API │  · 使用窗口：抽取 + 记录        │
│  · SQLite 单文件库 (WAL)   │  · 数据窗口：学生/导入/日志/设置 │
│  · Win32：提权/自启/输入设备│  · 主题引擎 / 页签 / 过渡动画    │
└──────────────────────────┴──────────────────────────────┘
```

- **通信**：前端 `fetch` 调用 `http://127.0.0.1:<随机端口>/api/*`，本机回环 + 一次性 Token（Set-Cookie 注入，兼容 CSP）双重限制。
- **数据目录**：`%APPDATA%\Wang\MyClass\Guess\one`
  - `myclass.db` — SQLite（WAL）
  - `logs\app.log`、`imports\`、`exports\`、`runtime.json`
- **升级不影响数据**：安装包只覆盖程序目录，数据始终留在 `%APPDATA%`。

## 统一数据结构

所有业务表共用：`id`(uuid) / `created_at` / `updated_at` / `deleted_at`(软删) / `extra`(JSON)。

| 表 | 用途 |
|---|---|
| `classes` | 班级 |
| `students` | 学生（学号/姓名/性别/小组/标签/权重/累计抽中/最近抽中） |
| `draw_sessions` / `draw_items` | 抽取批次与明细（保留姓名快照） |
| `settings` | 键值设置（JSON value） |
| `events` | 审计日志（操作、错误、更新、权限等） |

## 功能（1.0.4）

### 抽取
- **随机源**：WCCS（加权信用冷却取样器，[GitHub](https://github.com/Yuanyuan5510/WCCS) / `pip install wccs`）——加权采样 + 冷却去重 + 长期信用校正，同一次多抽不重复、连续两次不抽同一人。
- **三种模式**（在「使用」窗口直接切换）：
  - **均衡**：全体参与；抽中次数少者优先，并尽量避开最近刚抽中的同学；**内置“近期回避”**（45 分钟窗口，刚抽中者权重降到 0.25）。
  - **不放回**：奖池只含本轮未抽中的人；抽完自动重置并提示；切换模式即重置奖池。
  - **纯随机**：全体等概率。
- **权重**：学生权重 1–99，三种模式下都生效；均衡模式对“抽得少的人”最多放大 4 倍，保证权重仍是主导因素（99:1 时高权重约占 96%）。
- 一次抽 1/2/3/5 人；揭晓动画可选 **滚动 / 老虎机 / 翻牌 / 无动画**，时长 0.6–4s；撒花 + 提示音。
- **点击抽取结果或记录里的姓名** → 查看该学生信息并直接修改（姓名/学号/性别/小组/标签/权重/状态）。
- 快捷键：`Alt+Enter` 快速抽取，`Ctrl+Alt+G` 全局显示/隐藏主界面。

### 界面
- **四视图**：`使用`（抽取 + 记录）/ `数据`（学生 / 导入）/ `更多`（设置 / 页签设置 / 日志 / 关于）/ `组件`（开发中），带切换过渡动画。
- **无边框窗口**：最小化 / 最大化 / 关闭为应用内纯图标按钮。
- **沉浸布局**：抽取舞台居中最大化（只影响抽取页，设置页仍可正常滚动与退出）。
- **屏幕边缘页签**：可拖动、磁吸左右屏幕边缘、展开/收回动画；样式支持 经典 / 胶囊 / 气泡；显示当前班级 + 一键抽取（不再显示轮次与在池人数）。
- **触摸优化**：
  - 判定：**有鼠标一律按非触摸**；无鼠标且检测到触摸点才进入触摸模式（也可手动“始终开启/关闭”）。
  - 触摸模式下**点击页签展开**，点/移到离页签较远的位置自动收起（20 秒无操作也会收起）。
  - 只扩大**命中区域**（伪元素外扩 7–8px），不改变按钮视觉尺寸。

### 个性化
- 主题色、背景（默认 / 纯色 / 渐变 / 图片 + 遮罩）、抽取动画、页签样式、整体布局、自定义文字（应用名/副标题/抽取按钮/提示语）。
- 背景自动对比度：亮色背景自动切深色文字，深色背景用浅色文字；非法渐变/图片会回退默认背景而不是整页空白。
- **主题包**：导出/导入 `.json`，格式与制作方法见 [docs/主题制作指南.md](docs/主题制作指南.md)。

### 系统
- **托盘常驻**：关闭窗口 = 隐藏到托盘；菜单可抽取、开关页签（与页签实际状态同步）、打开数据目录、退出。
- **开机自启**：默认开启（`--hidden` 后台启动）。
- **权限自愈**：权限不足时弹窗引导 UAC 提权，确认后整个应用以管理员身份自动重启。
- **运行日志**：抽取、导入、班级/学生增删改、设置变更、更新、权限、异常全部写入 `events` 表；「数据 → 日志」可按级别/类别筛选，并**一键导出**为文本文件（`数据目录\exports`）。
- **自动更新（固定通道，不可手动切换）**：
  - 版本：`https://ghfast.top/https://raw.githubusercontent.com/Yuanyuan5510/My_Class/main/guess_one/version.txt`
  - 安装包清单：`https://ghfast.top/https://raw.githubusercontent.com/Yuanyuan5510/My_Class/main/guess_one/download.txt`
  - 启动 6 秒后自动检查；发现新版本**自动下载**（校验 MZ 头与体积）→ **3 秒倒计时自动运行安装程序并重启**（可取消/立即安装）。
  - 下载地址暂不可用时会给出明确提示（当前 download.txt 为占位地址）。
- **开发者页**：设置 → 关于 → 开发者，打开独立窗口播放 60 秒 3D 介绍动画（`about/` 目录，字体与样式全部本地化，离线可用；需点「开始播放」）。

## 开发

```bash
npm run build:web                          # 构建前端到 frontend/dist
.venv\Scripts\python.exe backend\main.py   # 仅启动后端（浏览器可访问 API）
python tests\api_test.py                   # 后端端到端测试（79 项）
python tests\encoding_test.py              # .bat 编码回归测试
python scripts\seed_demo.py <数据目录>      # 灌演示数据
```

- 启动 Electron 前需清除 `ELECTRON_RUN_AS_NODE` / `NODE_OPTIONS`（`run.bat` 已处理）。
- 验收截图：`electron.exe . --screenshot=test.png`（主窗口 + 页签）；加 `GUESS_SHOT_DEV=1` 会同时验证页签样式联动与开发者页。

## 打包发布

```bat
scripts\package.bat                 rem 一键：前端 -> PyInstaller 后端 -> NSIS 安装包
scripts\package.bat --backend       rem 只重建后端 exe
scripts\package.bat --setup         rem 只重建安装包（需已有 build\py-dist）
```

- 产物在 `release\`：`GuessOne-Setup-<版本>.exe` 与 `win-unpacked\`。
- 打包结构：`app.asar`（外壳）+ `resources\{frontend-dist, backend, assets, about}`（Python 读不了 asar，前端/后端/about 放外部）。
- 若旧 `win-unpacked` 被系统句柄占用导致删除失败（`EBUSY` / trash 失败），换输出目录：
  ```bat
  set GUESS_RELEASE_DIR=release2
  python scripts\package.py --setup
  ```
- 安装包未签名，首次运行 SmartScreen 会提示“未知发布者”，选择“更多信息 → 仍要运行”。

## 发布新版本（自动更新）

1. 改版本号：`package.json` 与 `backend/core/version.py` 的 `APP_VERSION` 保持一致。
2. 打包，上传 `GuessOne-Setup-X.Y.Z.exe` 到可直链下载的位置。
3. 更新仓库里两个文本文件：
   - `guess_one/version.txt` → 新版本号（如 `1.0.4`）
   - `guess_one/download.txt` → 安装包直链（一行 http(s) 地址）
4. 已安装的客户端下次启动 6 秒后自动检查 → 自动下载 → 自动安装重启。

## 脚本编码约定（重要）

`scripts\*.bat` **只允许纯 ASCII + CRLF（无 BOM）**；所有中文提示交给 Python 打印（`backend/core/console.py` 会按控制台代码页输出）。`tests/encoding_test.py` 为此提供回归守卫。
