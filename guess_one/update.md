## 功能（1.0.3）

### 抽取
- **三种模式**（在「使用」窗口直接切换）：
  - **均衡**：全体参与；抽中次数少者优先，并尽量避开最近刚抽中的同学；**内置“近期回避”**（45 分钟窗口，刚抽中者权重降到 0.25）。
  - **不放回**：奖池只含本轮未抽中的人；抽完自动重置并提示；切换模式即重置奖池。
  - **纯随机**：全体等概率。
- **权重**：学生权重 1–99，三种模式下都生效；均衡模式对“抽得少的人”最多放大 4 倍，保证权重仍是主导因素（99:1 时高权重约占 96%）。
- 一次抽 1/2/3/5 人；揭晓动画可选 **滚动 / 老虎机 / 翻牌 / 无动画**，时长 0.6–4s；撒花 + 提示音。
- **点击抽取结果或记录里的姓名** → 查看该学生信息并直接修改（姓名/学号/性别/小组/标签/权重/状态）。
- 快捷键：`Alt+Enter` 快速抽取，`Ctrl+Alt+G` 全局显示/隐藏主界面。

### 界面
- **双视图**：`使用`（抽取 + 记录）与 `数据`（学生 / 导入 / 日志 / 设置），带切换过渡动画。
- **无边框窗口**：最小化 / 最大化 / 关闭为应用内纯图标按钮。
- **沉浸布局**：抽取舞台居中最大化（只影响抽取页，设置页仍可正常滚动与退出）。
- **屏幕边缘页签**：可拖动、磁吸左右屏幕边缘、展开/收回动画；样式支持 经典 / 胶囊 / 气泡；显示当前班级 + 一键抽取（不再显示轮次与在池人数）。
- **触摸优化**：
  - 判定：**有鼠标一律按非触摸**；无鼠标且检测到触摸点才进入触摸模式（也可手动“始终开启/关闭”）。
  - 触摸模式下**点击页签展开**，点/移到离页签较远的位置自动收起（20 秒无操作也会收起）。
  - 只扩大**命中区域**（伪元素外扩 7–8px），不改变按钮视觉尺寸。

### 个性化
- 主题色、背景（默认 / 纯色 / 渐变 / 图片 + 遮罩）、抽取动画、页签样式、整体布局、自定义文字（应用名/副标题/抽取按钮/提示语）。
- 背景自动对比度：亮色背景自动切深色文字，深色背景用浅色文字；非法渐变/图片会回退默认背景而不是整页空白。
- **主题包**：导出/导入 `.json`，格式与制作方法见 [docs/主题制作指南.md](docs/主题制作指南.md)。

### 系统
- **托盘常驻**：关闭窗口 = 隐藏到托盘；菜单可抽取、开关页签（与页签实际状态同步）、打开数据目录、退出。
- **开机自启**：默认开启（`--hidden` 后台启动）。
- **权限自愈**：权限不足时弹窗引导 UAC 提权，确认后整个应用以管理员身份自动重启。
- **运行日志**：抽取、导入、班级/学生增删改、设置变更、更新、权限、异常全部写入 `events` 表；「数据 → 日志」可按级别/类别筛选，并**一键导出**为文本文件（`数据目录\exports`）。

  - 安装包清单：`https://ghfast.top/https://raw.githubusercontent.com/Yuanyuan5510/My_Class/main/guess_one/download.txt`
